1. The parent class of the Programmer class is the Employee class. The Programmer class inherits the properties and methods of Employee, allowing code to be reused.

2. I would place the Intern class under the Employee class, at the same level as the Programmer class. This is because an intern is also an employee and can share common properties and methods, such as name, salary or allowance, and work responsibilities, while having specific duties of their own.
